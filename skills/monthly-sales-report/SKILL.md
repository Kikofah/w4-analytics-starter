# รายงานยอดขายรายเดือน · บ้านสบาย ช็อป

ผลลัพธ์คือรายงาน Markdown 1 หน้าที่ผู้บริหารอ่านจบได้ในนาทีเดียว ตัวเลขทุกตัวต้องคำนวณจากไฟล์จริง และตรวจย้อนกลับได้

## นิยาม (ใช้ตามนี้เสมอ)

ตัวเลขของร้านจะเทียบกันข้ามรายงานได้ก็ต่อเมื่อทุกคนใช้นิยามเดียวกัน ถ้าผู้ใช้ขอนิยามอื่น เช่น รวมค่าส่ง ให้ทำแยก และระบุในรายงานชัด ๆ ว่าไม่ใช่นิยามมาตรฐาน

- **ยอดขายสุทธิ** = `qty × unit_price × (1 − discount_pct/100)` เฉพาะแถวที่ `status == "จัดส่งสำเร็จ"` **ไม่รวม** `shipping_fee`
- **กำไรขั้นต้น** = ยอดขายสุทธิ − `qty × unit_cost` (`unit_cost` อยู่ใน products.csv เชื่อมด้วย `product_id` ถ้าไม่มีไฟล์นี้ให้ข้ามบรรทัดกำไร)
- **AOV** = ยอดขายสุทธิ ÷ จำนวนคำสั่งซื้อที่จัดส่งสำเร็จ
- **อัตรายกเลิก / อัตราคืน** = จำนวนคำสั่งซื้อสถานะนั้น ÷ คำสั่งซื้อทั้งหมดของเดือน × 100 (ตัวหารรวมคำสั่งซื้อที่ยกเลิกด้วย)
- **เดือน** = 7 ตัวอักษรแรกของ `order_datetime` (YYYY-MM)
- ไฟล์ CSV เป็น UTF-8 มี BOM ให้อ่านด้วย `encoding="utf-8-sig"` ไม่อย่างนั้นชื่อคอลัมน์แรกจะเพี้ยน

ความผิดพลาดที่พบบ่อยที่สุดคือลืมกรอง status หรือเผลอรวมค่าส่ง ซึ่งทำให้ยอดสูงเกินจริง ขั้นตอนตรวจข้อมูลด้านล่างมีไว้จับเรื่องนี้

## ขั้นตอน

### 1. ตรวจข้อมูลก่อนคำนวณ

รันสคริปต์ในโหมดตรวจ แล้วแสดงผลให้ผู้ใช้เห็นก่อนรายงาน:

```bash
python scripts/report.py <path>/orders.csv --check
```

ผลที่ต้องรายงาน:
- **จำนวนแถว** และจำนวนคำสั่งซื้อไม่ซ้ำ ถ้าสองค่านี้ไม่เท่ากัน แปลว่า 1 แถวไม่ใช่ 1 คำสั่งซื้อ ต้องแจ้งผู้ใช้
- **จำนวนแต่ละ status** ปกติมี 3 ค่า คือ จัดส่งสำเร็จ, ยกเลิก, คืนสินค้า ถ้าเจอ status อื่นให้ถามผู้ใช้ก่อนว่าจะนับอย่างไร
- **ช่วงเดือนที่มีข้อมูล** ถ้าเดือนที่ขอไม่อยู่ในช่วงนี้ ให้บอกผู้ใช้ ห้ามเดาตัวเลข
- **ยอดรวมทุกสถานะเทียบกับยอดเฉพาะจัดส่งสำเร็จ** ใส่ไว้ให้ผู้ใช้เห็นว่าการกรอง status ทำให้ตัวเลขต่างกันเท่าไร

### 2. สร้างรายงาน

```bash
python scripts/report.py <path>/orders.csv 2026-03 [--products <path>/products.csv] -o monthly_report.md
```

- ถ้าผู้ใช้ระบุเดือนเป็นภาษาไทย เช่น "มี.ค. 2026" หรือ "มีนาคม 69" ให้แปลงเป็น `YYYY-MM` ก่อน (พ.ศ. − 543 = ค.ศ.)
- ถ้าไม่ระบุเดือน ให้ใช้เดือนล่าสุดที่มีข้อมูล แล้วบอกผู้ใช้ว่าเลือกเดือนไหน
- ถ้ามี products.csv ให้ใส่ `--products` ด้วย เพื่อให้รายงานมีกำไรขั้นต้น

สคริปต์ใช้แค่ pandas ถ้ารันไม่ได้ ให้คำนวณเองตามนิยามข้างบน แต่ต้องได้ตัวเลขชุดเดียวกัน

### 3. เติมข้อสังเกตแล้วส่งมอบ

สคริปต์เว้นหัวข้อ "ข้อสังเกต" ไว้ ให้เขียน 2–3 ข้อที่อิงตัวเลขในรายงานเท่านั้น เช่น ยอดเปลี่ยนจากเดือนก่อนกี่ %, สินค้าอันดับ 1 คิดเป็นสัดส่วนเท่าไร, อัตรายกเลิกสูงหรือต่ำผิดปกติไหม อย่าเดาสาเหตุที่ข้อมูลไม่ได้บอก ถ้าอยากเสนอสมมติฐาน ให้เขียนว่าเป็นสมมติฐาน

## โครงรายงาน 1 หน้า

ใช้โครงนี้ทุกครั้ง ผู้อ่านจะได้หาตัวเลขเจอที่เดิมทุกเดือน:

```markdown
# รายงานยอดขายประจำเดือน YYYY-MM · บ้านสบาย ช็อป

ข้อมูลเดือนนี้ N คำสั่งซื้อ · จัดส่งสำเร็จ a · ยกเลิก b · คืนสินค้า c

## ภาพรวม
| ตัวชี้วัด | ค่า |
| ยอดขายสุทธิ | … บาท |
| ยอดขายสุทธิเดือนก่อน (YYYY-MM) | … บาท |
| เปลี่ยนแปลงจากเดือนก่อน | +… บาท (+…%) |
| กำไรขั้นต้น | … บาท (…%)        ← เฉพาะเมื่อมี products.csv
| AOV | … บาท |
| อัตรายกเลิก | …% |
| อัตราคืนสินค้า | …% |

## 5 สินค้าขายดี (ตามยอดขายสุทธิ)
| อันดับ | รหัส | สินค้า | จำนวนชิ้น | ยอดขายสุทธิ |

## ข้อสังเกต
- 2–3 ข้อ อิงตัวเลขด้านบน

---
นิยามสั้น ๆ ท้ายหน้า
```

ถ้าเป็นเดือนแรกของข้อมูลและไม่มีเดือนก่อนให้เทียบ ให้เขียนว่า "ไม่มีข้อมูล" ห้ามเว้นว่างหรือใส่ 0

## ตัวอย่างค่าที่ถูกต้อง (ใช้ตรวจตัวเอง)

orders.csv ชุดเต็มของร้าน (ปีงบ ต.ค. 2025 – ก.ย. 2026):
- 17,529 แถว · จัดส่งสำเร็จ 16,249 · ยกเลิก 790 · คืนสินค้า 490
- ยอดขายสุทธิทั้งปี 14,107,737.05 บาท
- เดือน 2026-03 ยอดขายสุทธิ 1,147,155 บาท (เดือนก่อน 962,379 บาท, +19.20%) · อัตรายกเลิก 5.13% · อัตราคืน 3.16% · สินค้าอันดับ 1 คือเครื่องดูดฝุ่นไร้สาย

ถ้าได้ตัวเลขไม่ตรงกับชุดเต็มนี้ ให้ตรวจการกรอง status และค่าส่งก่อน ไฟล์ตัวอย่างที่ผู้ใช้ให้มาอาจเป็นชุดย่อยซึ่งตัวเลขจะต่างออกไป แบบนั้นถือว่าปกติ
